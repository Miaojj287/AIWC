# 查证历史（带证据）

用户问历史事实时，按以下顺序做，不要跳步：

1. **先定范围**。用 `list_contacts` / `list_sessions` 把人名、群名解析成 sessionId；范围不明确时问一句，不要全局乱搜。
2. **先关键词再语义**。`search_messages` 命中 → 直接用；命中太少或问题偏抽象 → `semantic_search`。
3. **每条结论必须落到锚点**。用 `get_context` 展开命中前后 ±10 条，确认语境后再下结论；引用时写「时间 · 会话 · 发送者：原文（≤60 字）」并附 anchor。
4. **说清覆盖范围**。搜索结果里的 `coverage` 字段要如实转述（例如只覆盖最近 20 个会话），不要把「没搜到」说成「没发生过」。
5. **不做推断性指控**。原文没有明说的意图、情绪，只能标注为「推测」。

输出结构：一句结论 → 证据列表（3 条以内，每条带锚点）→ 覆盖范围与不确定性。
