# 自动回复迁移与验收

2026-09-08。参考 `example/AIWC_ORG/electron/services/replyTileService.ts` 和 `autoReplyService.ts`，接入当前 Substrate → Gateway → SQLite 草稿/记录 → 回复台架构。

## 功能对应

| 原功能 | 当前落点与适配 |
| --- | --- |
| 后台发现新消息、连续消息合并 | `electron/main/services/autoReplyMonitor.ts`：事件订阅 + 轮询兜底，5 秒安静窗口，不依赖聊天页或未读数；首次看到某会话时若最后一条是对方发的则立即补回一次，之后按新消息触发；`triggerNow` 提供手动触发 |
| 新消息取代旧候选、本人回复后停止 | 监听器取消窗口，AutoReplyService 中止旧生成并废弃旧草稿；发送前再次检查账户、最新消息和规则 |
| 风格、候选数量、深度上下文 | `autoReplyGenerate.ts`：6 种风格、1–5 条候选、最近 30/120 条消息、缓存语音转写、最多 3 张待回复图片（模型支持视觉时） |
| 自画像、对方画像 | 适配当前 AI 克隆人格与对方画像；使用所选人格及表达样本，深度模式加入关系画像，模仿风格参考本人历史措辞 |
| 自定义回复要求 | 规则提示词实际进入生成请求；聊天、画像、图片作为参考数据，候选生成不开放执行工具 |
| 候选、重试、跳过 | 回复台可切换候选、编辑后发送、重新生成、拒绝；生成失败与发送失败均有真实错误和重试入口 |
| 自动倒计时、取消 | 全局建议/确认/自动模式与单规则确认设置共同决定行为；可暂停倒计时转为编辑确认 |
| 串行发送与气泡节奏 | UI 注入队列串行，气泡间隔 900–2600ms、队列间隔 2500–7000ms，忙碌时最多重试 2 次 |
| 发送核验、熔断恢复 | 数据库回读校验新消息，排除原有同文消息；保留一次补按 Return 和误发会话探测，失败熔断并显示恢复入口 |
| 记录与重启 | 草稿保留审计记录和通道上下文；确认/建议草稿可恢复，自动草稿重启不补发；退出等待进行中的生成和发送结束后关闭记录库 |

## 当前产品行为

- 规则编辑页与回复台在连接异常 / 演示数据 / 发送熔断时显示状态卡，正常时不占位置。
- 固定文案、AI 生成、转人工共用规则门控，时段与触发条件继续生效；转人工支持桌面、声音和文件传输助手提醒。
- 本地规则绑定微信账户，账户切换使旧任务失效；启用其他账户的旧规则会提示重新保存。
- 前端保存状态包含新增风格/深度/候选数，规则列表实时更新；统一回复台标签标识，避免重复标签。
- 正式产品桥接不回退到模拟数据。开发验收入口 `dev/fixtures/autoreply-preview.html` 仅使用内存模拟桥接，不连接真实联系人。

## 验证与边界

- 相关 Gateway、监听、生成、端到端服务链路、回复台、规则模型与模拟桥接回归测试通过。
- 服务链路测试用模拟微信注入器与可变消息库串起新消息 → 安静窗口 → 生成 → 倒计时 → 发送 → 回读 → 记录；覆盖本人回复不再触发。
- 浏览器验证规则配置、候选切换、修改后发送、计数刷新、回复台标签去重。
- 类型检查、定向 ESLint 与生产构建通过。构建仍有已有的打包选项/依赖注释与包体积提示。
- 未对真实微信联系人执行发送，也未用真实模型费用进行验收；真实环境仍依赖已配置模型、微信连接和注入权限。
- 深度模式按当前产品适配为更多历史与人格/关系资料，不搬入旧系统另起 Agent 的工具执行环境。没有转写缓存的语音保留类型提示；无法解析的图片跳过。现有通道不支持撤回时明确返回不可撤回，不伪造成功。
